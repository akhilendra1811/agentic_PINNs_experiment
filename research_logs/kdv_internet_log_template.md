For EACH actual web search, web page, public document or code repository visit, append:

- UTC timestamp:
- Search tool / browser / research system used:
- Search query (if any):
- Visited URL (full exact URL, not just a publication title):
- Source type (paper, preprint, documentation, code, search-results page):
- Purpose / method investigated:
- What the source actually establishes, and any uncertainty:
- Impact on ideas or trial numbers:
- Access status (success, sign-in required, paywall, failed):

- Google Scholar: https://scholar.google.com/
- Google Scholar Labs: https://scholar.google.com/scholar_labs
- arXiv: https://arxiv.org/
